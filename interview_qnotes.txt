# Technical Definitions — Interview Preparation

## 1. Redux(library)

**Redux is a state management library used to store and manage application state in a predictable way.**

## 2. FastAPI(python library\)

**FastAPI is a modern Python framework used to build fast and scalable web APIs.**

## 3. JWT

**JWT (JSON Web Token) is a signed token used to securely transfer information between a client and server, commonly for authentication.**

## 4. OAuth 2.0

**OAuth 2.0 is an authorization framework that allows an application to access a user's resources without sharing the user's password.**

## 5. Authentication

**Authentication:** Verifies the user's identity.
**Example:** Login with username/password.

## 6. Authorization

**Authorization:** Determines what an authenticated user can access.
**Example:** Admin can delete users, but a normal user cannot.

## 7. REST API (Representational State Transfer )

**REST API is an API style that uses HTTP methods like GET, POST, PUT, PATCH, and DELETE to work with resource  request and reposne in JSON format.**

## 8. GraphQL

**GraphQL is an API query language that allows clients to request exactly the data they need.**

## 9. SOAP API (Simple Object Access Protocol)

**SOAP is a protocol that uses XML-based messages for communication between applications.**

## 10. WebSocket API

**WebSocket is a communication protocol that provides a persistent two-way connection between the client and server for real-time communication.**

## 11. gRPC

**gRPC is a high-performance framework that allows applications or services to call methods on another service.**

## 12. Webhook

**A webhook is a mechanism where one application automatically sends data to another application when a specific event occurs.**

## 13. Next.js
 
**Next.js is a React framework for building full-stack web applications with features like routing, server-side rendering, and server-side functionality.**

## 14. CI/CD

**CI/CD is a development process that automates code integration, testing, building, and deployment.**

**Typical Flow:**
**Feature Branch → Commit → Push → Merge Request/Pull Request → CI → Build/Test → Code Review → Merge → CD → Deploy**

**CI — Continuous Integration:** Automatically builds and tests code changes when developers push or merge code.

**CD — Continuous Delivery/Deployment:** Automates preparing or deploying successfully tested code to environments such as staging or production.

## 15. AWS

**AWS (Amazon Web Services) is a cloud platform that provides on-demand services such as servers, storage, databases, networking, security, and monitoring.**

### Important AWS Services

* **EC2:** Virtual servers used to run applications.
* **S3:** Object storage for files, images, videos, and backups.
* **RDS:** Managed relational databases such as MySQL and PostgreSQL.
* **Lambda:** Runs code without managing servers.
* **DynamoDB:** Managed NoSQL database.
* **CloudFront:** CDN used to deliver content faster.
* **Route 53:** DNS service for managing domains and routing traffic.
* **VPC:** Private virtual network for AWS resources.
* **IAM:** Manages users, roles, permissions, and access.
* **CloudWatch:** Monitoring and logging service.
* **API Gateway:** Service for creating and managing APIs.
* **ECR:** Stores Docker container images.
* **ECS:** Runs and manages containerized applications.

## 16. Python

**Python is a high-level programming language known for its simple syntax and wide range of applications, including web development, automation, AI, and data science.**

## 17. ngrok

**ngrok is a tunneling tool that creates a public URL for a locally running application.**

## 18. Linux

**Linux is an open-source operating system widely used for servers, cloud infrastructure, development, and embedded systems.**

## 19. Electron.js

**Electron is a framework for building cross-platform desktop applications using web technologies such as HTML, CSS, and JavaScript.**

## 20. C

**C is a fast, general-purpose programming language that provides low-level memory control and is widely used for system-level and embedded programming.**

# Database

## 21. SQL

**SQL (Structured Query Language) is a language used to store, retrieve, update, and manage data in relational databases.**

**Example:** MySQL, PostgreSQL, and SQLite use SQL.

## 22. SQLite

**SQLite is a lightweight, serverless relational database that stores the entire database in a single file.**

**Example:** It is commonly used in mobile apps, desktop applications, and offline-first applications.

## 23. PostgreSQL

**PostgreSQL is an open-source, powerful relational database management system known for reliability, advanced SQL features, and scalability.**

**Example:** It is commonly used for web applications, backend systems, and large-scale applications.

### Easy Difference

**SQL → Language**
**SQLite → Lightweight database**
**PostgreSQL → Powerful relational database**

# AI Concepts

## 24. Predictive AI

**Predictive AI uses data and machine learning to predict future outcomes or events.**

**Example:** Predicting customer demand or detecting possible fraud.

## 25. Generative AI

**Generative AI creates new content such as text, images, audio, video, or code based on patterns learned from data.**

## 26. Agentic AI

**Agentic AI refers to AI systems that can plan, make decisions, use tools, and take actions to achieve a goal.**

### Easy Difference

**Predictive AI → Predicts**
**Generative AI → Creates**
**Agentic AI → Acts**

# Verification vs Validation

**Verification:** Checks whether we are building the product correctly according to the specified requirements.

**Validation:** Checks whether we are building the right product according to the user's or business needs.

**Easy Memory:**
**Verification → Correctly built?**
**Validation → Correct product?**
